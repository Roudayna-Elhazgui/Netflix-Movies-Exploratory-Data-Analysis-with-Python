# Netflix Movies: Exploratory Data Analysis with Python

An exploratory data analysis project using Python to investigate Netflix's movie catalog, with a particular focus on movies released during the 1990s.

The project explores Netflix's content dataset to identify trends and patterns in movie releases, genres, and durations, with the goal of understanding the characteristics of 1990s cinema and identifying insights that could support a production company specializing in nostalgic content.

### Dataset
The analysis uses `netflix_data.csv`, containing information about Netflix movies and TV shows, including:
- Show title and type
- Director and cast
- Country of origin
- Release year
- Duration
- Genre
- Description

### Objectives
- Explore and analyze Netflix's movie catalog.
- Focus on movies released between 1990 and 1999.
- Investigate movie durations and genre distributions.
- Identify patterns and trends in 1990s movies.

### Tools & Technologies
- **Python**
- **Pandas**
- **Data Visualization**
- **Exploratory Data Analysis (EDA)**
